# Model cards

Each Phonon model carries its own model card on Hugging Face, with its evaluation, licence and attribution. The cards
are maintained there, so this file points at them rather than keeping a copy that could fall out of date.

| Model | Download | Card |
|---|---:|---|
| **Phonon-2** (`phonon-2`), the current model | 164 MB | <https://huggingface.co/FermionResearch/Phonon-2> |
| Phonon-1 (`phonon-1`) | 415 MB | <https://huggingface.co/FermionResearch/Phonon-1> |
| Phonon-1 Big (`phonon-1-big`) | 581 MB | <https://huggingface.co/FermionResearch/Phonon-1-Big> |
| Phonon-1 Micro (`phonon-1-micro`) | 285 MB | <https://huggingface.co/FermionResearch/Phonon-1-Micro> |

Accuracy and speed for each model are on its page at [fermionresearch.com/models](https://fermionresearch.com/models/).
